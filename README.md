# GameBoy Live

> 一个跑在浏览器里的 GB / GBC / GBA 掌机模拟器：把卡带文件拖进页面就能玩，外框会按机型换成对应颜色的掌机外壳。
> 不需要安装、不需要注册、不上传任何文件；**也不内置任何游戏**——你拖进去什么，它就模拟什么。

## 开始玩

1. 打开网页。首屏会亮起一台待机的掌机，屏幕提示未插卡。
2. 把 `.gba` / `.gbc` / `.gb` 文件**拖进页面**，或者点屏幕选择文件。
3. 出现「点击开始」时点一下屏幕 —— 浏览器要求先有一次点击才允许出声，之后就一直能玩了。

机身右上方的指示灯就是状态读数：`OFF` 待机、`LOAD` 载入中、`RUN` 运行中、`HOLD` 已暂停、`ERR` 出错。**按它（或按整块屏幕）就是暂停 / 继续**。

## 支持的文件

| 格式 | 说明 |
|---|---|
| `.gba` / `.gbc` / `.gb` | 直接拖入即可，机型按文件头自动识别，外壳跟着换 |
| `.zip` | 只读取压缩包里的**第一个** ROM；包里没有 `.gba` / `.gb` / `.gbc` 会报错 |
| 大小上限 | 单个文件 32 MB（超出通常是拖错了文件，比如整张镜像） |

- 存档（`.sav`、`.srm`）**不能**当成游戏拖进来，只能通过存档面板导入。
- 拖进来时如果画面提示「文件太小 / zip 结构损坏 / 浏览器解不了 zip」，按提示换文件或先手动解压。

## 键盘与触屏

外壳上的 A / B / 十字键 / Start / Select / L / R **本身就是按钮**，鼠标点、手指按都可以，十字键与 A 键可以同时按。

默认键位：

| 动作 | 按键 | 动作 | 按键 |
|---|---|---|---|
| 上 / 下 / 左 / 右 | `W` / `S` / `A` / `D` | A / B | `L` / `K` |
| Start / Select | `B` / `V` | L / R（仅 GBA） | `Q` / `O` |

- GB / GBC 没有肩键，L / R 不会出现。
- **改键**：`设置 → 按键`，或菜单里的「键位」。点一行 → 提示「请按键」→ 按下新键即刻生效。同一按键不能绑两个动作，冲突时会询问是否交换；点「恢复默认键位」可全部还原。
- **手柄**：支持标准映射的游戏手柄，插上即用（浏览器里按一下手柄按钮才会被识别）。
- 系统快捷键：`` ` `` 切换整机 / 面板模式（该键未被绑定为游戏按键时）；`Esc` 暂停 / 继续；面板打开时 `Esc` 关闭面板。

## 显示模式

| | 整机 | 面板 |
|---|---|---|
| 画面 | 整套外壳，按键旁刻着当前键位 | 只剩屏幕，屏幕最大化 |
| 适合 | 刚开始玩、还在记键位 | 熟练之后，沉浸玩 |
| 切换 | 菜单里的「整机 / 面板」，或按 `` ` `` | 同左 |

- 切换是瞬时的，游戏不会中断。
- 默认值跟着屏幕走：大屏进整机、小屏进面板；你手动选过之后就固定下来，刷新也保持。
- 面板模式下没有机身按键可点，会自动启用半透明触控层（透明度可在设置里调，也可以强制开/关）。

## 滤镜

`自动`（DMG 自动上四阶绿，其余原色）、`原色`、`点阵绿`、`栅格`、`扫描线`。菜单里的滤镜按钮是循环切换，设置面板里可以直选。

画面其它两档：

- **像素锐化**：开（默认）像素边缘硬朗；关掉交给浏览器插值，小屏看着更柔和。
- **圆角遮罩**：默认关。开了画面四角按外框弧线裁切；部分浏览器（尤其 Safari）对画布圆角裁切不稳定，开了也可能仍是直角。

## 存档与截图

| 类型 | 什么时候发生 | 存在哪 |
|---|---|---|
| 卡带存档（SRAM） | 自动：约每 15 秒，以及暂停、关闭页面、退出游戏时 | 本机浏览器存储，按 ROM 分开 |
| 即时存档 | 手动，共 **4 个槽**，带缩略图和时间 | 本机浏览器存储 |
| 设置（键位、音量、模式、语言…） | 改动即存 | 本机浏览器存储 |

暂停后打开存档面板，可以：

- **保存 / 读取 / 删除** 4 个即时存档槽（覆盖前会确认）。
- **导出 `.sav`**：把当前卡带存档下载成文件，可拿去喂别的模拟器或做备份。没有电池存档的 ROM 会提示「还没有卡带存档」。
- **导入 `.sav`**：覆盖当前 ROM 的卡带存档。导入会重启内核（内核只在启动时读存档），从暂停状态恢复。
- **截图**：把当前画面存成 PNG，文件名带卡带标题和时间。

> 即时存档和机型/内核版本绑定，别的机器上读同一份即时存档可能报错；跨设备保进度请用 `.sav`。
> 浏览器在磁盘吃紧时可能清理站点数据。想要更稳，去 `设置 → 关于 → 存档保护` 点「申请」，让浏览器承诺不清理；被拒也不影响玩，只是重要进度建议顺手导出 `.sav`。

## 游戏面板（最近打开）

菜单里的「游戏」面板分两段：

- **随项目提供**：只有部署时打包了预置游戏才会出现（默认没有）。
- **最近打开**：你拖进来过的 ROM，文件存在本机，下次点一下直接玩，不用再找文件。最多保留 **8 个**，超出后旧的自动清理；单条可以删。

不想留副本：`设置 → 关于 → 缓存 ROM` 关掉后不再新增缓存（已有的保留），下面的「清空」可以一次清干净。

## 设置项

**显示**：显示模式、语言、滤镜、像素锐化、圆角遮罩、屏幕按键（自动 / 开 / 关）、触控层透明度、键位标注。

**按键**：完整键位表、点行改键、冲突处理、恢复默认。

**声音**：音量滑杆、静音。静音只影响输出，游戏照常运行。

**关于**：内核与许可、无 ROM 声明、快捷键速查、存档保护（申请不被清理）、缓存 ROM 开关 + 本地缓存数量与清空。

## 界面语言

右上菜单**顶部**的 `中 | EN`，或 `设置 → 显示 → 语言`。切换立即生效、刷新后保持。

- 第一次进来跟随浏览器语言（`zh-*` 给中文，其余给英文），之后以你点过的那档为准。
- ROM 文件名、卡带内部标题、机身丝印（`GAME BOY`、`RUN`/`HOLD` 等）不翻译 —— 那些是用户数据和硬件外观。

## 装到桌面 / 离线使用

- **Android / 桌面 Chrome、Edge**：地址栏右侧的「安装」按钮，或菜单里的「安装 GameBoy Live」。
- **iPhone / iPad Safari**：分享 → 「添加到主屏幕」。
- 装好后是一个独立窗口，没有地址栏。
- 离线时仍能打开外壳；已经进过「最近打开」的 ROM 一般还能接着玩，没缓存过的 ROM 需要联网重新选择。
- 需要通过 **https** 打开（本地 `localhost` 也算），`file://` 直接打开网页只能用最基础的功能，没有安装与离线能力。

## 手机上

- 竖屏、横屏都适配；横屏时外壳会横向撑满，工具栏折成一枚菜单键。
- 屏幕按键按 `pointer` 事件处理，支持多点同时按；不会触发长按菜单和双击缩放。
- 玩的时候会申请「屏幕常亮」，暂停或切到后台自动释放；浏览器不支持或拒绝时不影响游戏。
- **iPhone Safari 不支持网页内的元素级全屏**，所以全屏按钮不会出现 —— 用横屏 + 面板模式代替。

## 常见问题

**没声音？**
先在「点击开始」遮罩上点一下（浏览器要求手势后才允许播放音频）；再检查菜单里的音量是否被拉到 0、是否点了静音。

**画面卡 / 帧率低？**
菜单里的丝印行会实时显示 FPS。关掉「像素锐化」、换成 `原色` 滤镜、或切到面板模式都能减轻负担；后台标签页会自动暂停，切回来自动继续。

**刷新后存档还在吗？**
卡带存档和即时存档都存在本机浏览器里，刷新、关浏览器都还在。但**清理浏览器数据、换浏览器、换设备、无痕模式**都会丢，重要进度请导出 `.sav`。

**拖进去报错？**
- 「文件太小，不是有效的 ROM」：确认拖的是卡带文件，不是 `.sav` 或别的镜像。
- 「ROM 超过 32 MB」：大概率拖错了文件。
- 「zip 结构损坏 / 浏览器解不了 zip」：先手动解压，再拖里面的 ROM。
- 「本地缓存里找不到这个 ROM」：缓存被清掉了，重新选一次文件即可。

**换 ROM 会丢进度吗？**
切到别的 ROM 前会先把卡带存档写盘；即时存档按 ROM 分开存，不会互相覆盖。

**能快进吗？**
暂时不能，当前内核没有暴露倍速接口。

**能两台设备联机 / 交换吗？**
不做，本项目只提供本地单机。

## 兼容性

| 能力 | 要求 | 不满足时 |
|---|---|---|
| WebAssembly | 全主流浏览器 | 提示浏览器过旧 |
| 手指/鼠标按键 | Pointer Events | 老浏览器只能键盘 |
| 本地存档 | IndexedDB + OPFS | 降级为仅本次会话，并提示导出 `.sav` |
| 解压 `.zip` | 浏览器自带解压能力 | 提示先手动解压 |
| 屏幕常亮 | Chrome 84+ / Safari 16.4+ | 不常亮，游戏照常 |
| 安装为应用 | 需要 https / localhost | 当普通网页用 |

目标：**iOS Safari 16.4+ / Android Chrome 111+ / 桌面 Chrome、Edge、Firefox、Safari 最新两个大版本**。

## 隐私与许可

- **不上传**：拖入的 ROM、存档、截图全在浏览器本地处理，项目没有后端，也不发任何第三方统计请求。
- **不内置、不下载、不分发**任何游戏 ROM。玩什么由你自己提供，请确保你有权使用该文件。
- 模拟器内核 mGBA（wasm 编译版）为 **MPL-2.0**；本项目的代码为 **MIT**（见 `LICENSE`）。
- 界面上的 `GAME BOY` 等字样是对掌机外观的致敬性还原，与任天堂无关。

## 本地运行

需要 Node.js 20+：

```bash
npm install     # 会顺手把内核产物同步到 public/mgba/
npm run dev     # 本地开发
npm run build   # 产出静态站点到 dist/
```

推送 `main` 分支后由 GitHub Actions 构建并发布到 GitHub Pages；`.wasm` 作为普通静态资源返回，不需要任何特殊的响应头配置。
